# Tech Layoffs & Hiring Trends in E-Commerce (2024–2026)

## Project Overview

This data analytics project examines tech layoff trends, hiring dynamics, AI technology adoption, and corporate financial performance specifically within the **E-Commerce** ecosystem.

Starting from a raw dataset of 12,000 records across various global tech sectors, this analysis isolates **1,732 specific E-Commerce entries** to deliver contextual insights without distortion from other industry volatilities.

---

## Key Objectives & Scope

* **Data Collection**: Loading global tech industry trend datasets.
* **Data Filtering & Isolation**: Isolating 1,732 entries specific to the E-Commerce sector for focused analysis.
* **Data Cleaning & Optimization**:
* Automated checking and validation of missing values.
* Logical deduplication based on business entities (non-primary keys).
* Text format standardization and RAM optimization (converting types to `category`).
* Outlier observation across critical metrics (*layoffs count, stock growth, AI impact*) based on company scale (*Startup, Mid-size, Big Tech, Enterprise*).
